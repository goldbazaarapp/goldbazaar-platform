CUSTOMIZATION GUIDE
═══════════════════════════════════════════════════════════════════════════════

Change Gold Rates:
  Edit in GoldRateManager.mockRates:
  mockRates: { '24K': 7460, '22K': 6842 }

Change Update Frequency:
  Modify GoldRateManager.updateInterval:
  updateInterval: 5 * 60 * 1000  // Change 5 to desired minutes

Change Carousel Speed:
  Modify CarouselManager.autoScrollDelay:
  autoScrollDelay: 4000  // Change 4000 to desired milliseconds

Change Animation Duration:
  Edit CSS transitions and @keyframes:
  transition: opacity .6s var(--ease)  // Change .6s to desired time

Add News Items:
  Add new .news-card-live divs in HTML:
  <div class="news-card-live">...</div>

Add Vendors to Carousel:
  Duplicate .vendor-spotlight-card in carousel-track
