RECOMMENDED IMAGE DIMENSIONS:
  - Format: PNG with transparent background (preferred) or white background
  - Size: 400 x 200 px  (displayed at 80x80, but higher res = sharper on retina screens)
  - Aspect ratio: Landscape (2:1) works best for banners; square (1:1) also fine for logos
  - File size: Keep under 100KB per image for fast loading

HOW TO ADD A NEW VENDOR:
  1. Save the logo as images/jeweler-logos/vendor-name.png
  2. No code changes needed — the site automatically shows it in the card

If no image is found, the site falls back to a gold emoji icon automatically.
